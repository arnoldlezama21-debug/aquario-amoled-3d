# Acuario AMOLED 3D - Live Wallpaper Real

1. Abre en Android Studio > Open > carpeta LiveWallpaperAcuario
2. Espera a que Gradle sincronice
3. Conecta tu celular en modo depuración y Run, o Build > Generate Signed App Bundle
4. Para probar: en tu celular, mantén pulsado fondo > Fondos de pantalla > Fondos animados > Acuario AMOLED 3D
5. Para Play Store: crea cuenta de desarrollador ($25), sube el .aab, icono 512x512, capturas, descripción y política de privacidad.

El archivo index.html en assets/www es el acuario 3D (Three.js). Puedes editar colores/cantidad ahí.
